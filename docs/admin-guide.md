# 楽曲登録と管理画面の使い方

## 管理画面を開く

API・ワーカー・Laravelを起動し、管理者ユーザーでログインします。

```text
http://localhost:8080/admin/karaoke
```

403エラーの場合、そのユーザーの`is_admin`が`true`になっていません。[管理者設定](getting-started.md#7-最初の管理者を設定)を確認してください。

## 素材を準備

1曲につき次の4ファイルが必要です。

| 項目 | 形式 | 内容 |
|---|---|---|
| 元音源 | WAV／MP3 | 歌と伴奏が入った完成音源 |
| カラオケ音源 | WAV／MP3 | 歌声を除いた伴奏 |
| アカペラ音源 | WAV／MP3 | 基準になる歌声 |
| 歌詞 | TXT | UTF-8、表示したい行ごとに改行 |

音源3つは同じ開始位置・ほぼ同じ長さにしてください。2秒を超える長さの差があると解析は失敗します。

歌詞例：

```text
最初の歌詞です
次の歌詞です

サビの歌詞です
```

空行は解析時に除外されます。タイムスタンプをTXTへ記入する必要はありません。

## 楽曲を登録

1. 曲名、アーティスト、難易度1～10を入力します。
2. 3音源と歌詞TXTを選択します。
3. 「登録して解析開始」を押します。
4. 「解析ジョブを開始しました」と表示されることを確認します。

1ファイルの上限は音源250MB、歌詞2MBです。アップロード途中で画面を閉じないでください。

## 状態の意味

| 状態 | 意味 | 対応 |
|---|---|---|
| `draft` | 楽曲情報だけ作成済み | 素材登録処理を確認 |
| `analyzing` | ワーカーが処理中 | 完了まで待つ |
| `review_required` | 自動生成完了 | タイムラインを確認 |
| `published` | アプリへ公開済み | Flutterから確認 |
| `failed` | 解析失敗 | Workerログを確認 |

一覧は現状自動更新されません。ブラウザーを再読み込みして状態を確認してください。

## 歌詞タイムラインを確認

`review_required`になったら「タイムライン確認」を押します。

- 開始・終了時刻の単位はミリ秒です。
- 1秒は1000ミリ秒です。
- 行は上から時間順に並べます。
- 次の行の開始時刻は、前の行の終了時刻より前にできません。
- 信頼度が低い行ほど実音源を聞いて確認してください。

現在の管理画面は数値編集方式です。波形表示、ドラッグ編集、単語単位編集は今後の拡張です。

## 公開

タイムラインを保存して一覧へ戻り、「公開」を押します。公開後、Flutterアプリの楽曲一覧API`GET /v1/songs`に表示されます。

元音源とアカペラ音源はアプリへ公開されません。アプリへ配信されるのは変換済みカラオケ音源と歌詞タイムラインです。

## 解析ログを見る

Dockerで起動している場合：

```powershell
docker compose logs -f worker
```

APIログ：

```powershell
docker compose logs -f api
```

ログ表示を止めるだけなら`Ctrl+C`を押します。コンテナ自体は停止しません。
